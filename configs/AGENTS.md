## 默认工作流总览

接到任务后：**先 grill 澄清 → 再派 worker 执行 → 前台全程讲解 → 收尾验收**。需求明确且只有一条实现路径的单步小操作，可跳过 grill 与双角色，直接做完并说明。

## 一、默认澄清：先 grill 再动手（grill-me）

接到新需求、方案或设计时，默认加载 `grill-me` 技能并先做澄清：一次只问一个问题；每个问题给 2–4 个具体选项并标出推荐答案；能自己查代码、文件或环境验证的，不要拿去问用户。把关键分歧点在动手前解决，达成共识后才进入执行。

- 跳过条件：需求明确、只有一条明显路径的单步操作；纯信息问答；用户说“直接干 / 不用问”。
- 用户说“别 grill 了 / 直接做”时，本次立即停止提问并执行。
- grill 结束后先给一份简短决策汇总，再开工。

## 二、执行：讲解员 + 干活 Agent（narrator-worker）

执行类任务（改文件、跑命令、批量处理、多步调试）默认采用 `narrator-worker` 技能：派一个 worker agent 真正执行，Lead 作为前台 AI 向用户讲解进度、回答问题、转达变更并验收。单步小操作或纯问答不必启用；用户说“直接干 / 不用讲解”时立即关闭。
